# PV 三维排布可视化

纯前端、零依赖单文件（`index.html`）的光伏组件三维排布工具：把航拍倾斜摄影 OBJ 在本地浏览器里打开，圈屋面、建排布方案，生成组件阵列并统计。模型文件只在浏览器本地内存中解析，不上传。

## 打开方式

直接用浏览器打开 `index.html` 即可，断网可用。

## 功能

- 内置演示屋顶；拖拽本地 OBJ 模型文件夹（含 MTL 与 JPG/PNG 贴图），按 `mtllib`/`usemtl`/UV 关系加载
- 三维旋转 / 缩放 / 平移；点选模型三角面确定屋面基准
- **排布方案库**：组件规格、倾角、行列数、组串单元（每串行数/列数、单元内间距、组串间距）、阵列旋转、位置微调、角度修正；方案可新建/编辑/删除，导出/导入 JSON 跨项目复用
- **多屋面管理**：每个屋面独立点选基准面、在模型表面逐点画多边形范围；一个屋面同一时间关联一个方案，可切换
- 阵列以西南角锚点向东北展开；按串分色显示；组件中心点多边形裁剪；不完整串单独标识
- 统计：每屋面小计（块数 / kWp / 面积 / 串数）+ 项目汇总
- 导出 PNG 效果图、排布参数 JSON（含方案库、屋面、关联关系）
- `metadata.xml` 方位解析（SRS / SRSOrigin）、模型包围盒尺寸、指北针

## 约定

- 单位：1 OBJ 单位 = 1 米；Z 轴向上
- 顶点导入不缩放，仅减包围盒中心做平移
