# pv-3d-layout

光伏三维排布可视化工具（MVP）：在倾斜摄影实景三维模型上叠加光伏组件阵列，做三维效果图与容量估算。

## 用法

- 用浏览器打开 `index.html` 即可。纯静态单文件，无后端、无构建，数据只在本地内存处理，不上传。
- 内置演示屋顶场景，开箱即用，可先走通全流程。
- 把倾斜摄影 OBJ 文件夹（`.obj` + `.mtl` + 贴图）整个拖入页面，自动按 `mtllib` 配对材质贴图，多分块自动合并。

## 功能（MVP）

- OBJ 文件夹载入：多分块合并，MTL 贴图渲染
- 点选模型三角面：定位阵列中心并读取该面法向
- 组件参数：长度 / 宽度 / 单块功率 / 倾角
- 排布参数：行数 / 列数 / 行间净距 / 列间净距 / 阵列旋转
- 位置微调：东西 / 南北 / 高度偏移
- 角度修正：俯仰 / 横滚（对齐真实屋面坡度）
- 实时统计：组件块数 / 装机容量 kWp / 组件总面积
- 导出：PNG 效果图、排布参数 JSON（向后兼容）
